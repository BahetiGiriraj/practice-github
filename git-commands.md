Setup & Config

1. git config --global user.name ""
   git config --global user.email "" 

what it does - set user/config option to all repo for an account 

2. git init - initall the git repo in a folder 



Basic Workflow

1. git add - add file to the git repo
2. git commit -m "" - commit the file , staged to tracked , means all the changes will be tracked now 


Viewing Changes

1. git status - give us the status of the folder/file (Untrack , staged , track) 
2. git log - give the history of the files , when they commit , who did it , where and the hash of that file
